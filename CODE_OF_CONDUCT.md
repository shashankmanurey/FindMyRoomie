# Code of Conduct

## Our Commitment

We want FindMyRoomie to be a welcoming, respectful, and constructive open-source community. Participation is open to everyone, regardless of background, identity, experience level, or location.

## Expected Behavior

- Be respectful, considerate, and collaborative.
- Give and receive feedback professionally.
- Focus on the work and assume good intent.
- Protect private information shared in issues, reviews, and discussions.
- Help keep technical discussions useful and accessible.

## Unacceptable Behavior

Harassment, discrimination, personal attacks, threats, sexualized attention, doxxing, publishing private information, and disruptive or abusive conduct are not acceptable.

## Enforcement

Project maintainers may remove comments, close discussions, reject contributions, or restrict participation when this code is violated. They will handle reports fairly and confidentially where possible.

Report concerns to the maintainers through the security or contact channel listed in the repository. Please do not include sensitive details in a public issue.

## Scope

This code applies in project spaces, issue trackers, pull requests, chats, and any setting where a person represents the FindMyRoomie project.
